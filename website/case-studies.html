Shivalaya Resorts: Smart Hospitality Operating System

Client: Shivalaya Resorts & Panache Luxury Spa · Production Status: Live & Operational
99.98%
Surge Concurrency Uptime
[01] THE CORE PROBLEM

Concurrent Table Ordering Collisions

High-volume guest surges caused ordering collisions. When 40+ resort guests scanned table QR codes simultaneously, standard web requests suffered from double-booking race conditions, missing kitchen tickets, and manual bill reconciliation delays.

[02] ARCHITECTURAL SOLUTION

3-App Ecosystem & Advisory Locks

Engineered a 3-application ecosystem: Guest QR Ordering App, Kitchen Display System (KDS), and Reception Admin. Concurrency was hardened using PostgreSQL transaction advisory locks (pg_advisory_xact_lock) to serialize order writes without table lockouts.

[03] REAL-TIME AUTOMATION

Sub-15s WhatsApp PDF Billing

Supabase database triggers listening to invoice settlements immediately invoke edge functions that generate branded dynamic PDF vouchers and dispatch them to guest WhatsApp accounts via MSG91 in under 15 seconds.

PRODUCTION STACK: React 18 SPA PostgreSQL Advisory Locks Supabase Realtime Webhooks MSG91 WhatsApp API Dynamic PDF Engine

Role: AI/ML Engineer (Abhayraj Singh) · Scope: 8 Cisco Enterprise Network Domains

Cosine Anti-Hallucination
[01] MISSION CHALLENGE

Zero-Tolerance Telecom Configs

Network engineers navigating tens of thousands of pages of proprietary Cisco documentation (Catalyst, Nexus, ACI, IOS-XE/XR) were prone to configuration delays. Public LLMs hallucinated non-existent CLI flags and risked leaking internal network topologies.

[02] VECTOR ARCHITECTURE

FAISS 768-Dim & Cosine Guardrail

Engineered a domain-isolated RAG pipeline utilizing FAISS 768-dimensional dense vector embeddings with a strict mathematical cosine similarity threshold (threshold ≥ 0.30). If no verified excerpt matched, the assistant explicitly abstained.

[03] FINE-TUNING & MCP

QLoRA 4-Bit Llama 3.2 + MCP

Fine-tuned Llama 3.2 via 4-bit QLoRA hosted on private on-premise Linux VMs. Integrated SLIM architecture with Model Context Protocol (MCP) for runtime tool discovery, querying live network telemetry securely.

PRODUCTION STACK: FAISS 768-Dim Dense Vectors Llama 3.2 QLoRA 4-bit Python FastAPI Model Context Protocol (MCP) Linux VM Fleet

[01] COMPLIANCE MANDATE

100+ Crew & 11 Certification Matrices

Tracking 100+ offshore crew members across 30+ personal attributes and 11 maritime certifications (BOSIET, STCW, Medical Fit-to-Work). Expired certifications incur severe port authority penalties.

[02] ZERO-TRUST NETWORK

Tailscale WireGuard Mesh VPN

Architected with a strict zero-trust posture: backend containers communicate exclusively through a private Tailscale WireGuard mesh network. Zero open ports are exposed to the public internet.

[03] AUTOMATED REPORTING

OpenPyXL Multi-Sheet Manifests

Built a high-performance Python OpenPyXL spreadsheet generation engine. With a single click, port logistics officers export complex multi-sheet manifests with automated color-coded expiry alerts.

PRODUCTION STACK: React 18 Dashboard Python FastAPI Tailscale WireGuard Mesh PostgreSQL RBAC OpenPyXL Engine
